# Registro de programas del usuario

> REQ-C2: Atlas NUNCA asume programas. Si una tarea menciona un programa
> no registrado aqui, preguntar UNA vez, registrar, y recordar.

## Programas registrados

### Navegadores
- **Google Chrome** — `C:\Program Files\Google\Chrome\Application\chrome.exe`
- **Microsoft Edge** — `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
- **Opera** — `C:\Users\Administrator\AppData\Local\Programs\Opera\opera.exe` (si existe)

### Desarrollo
- **Visual Studio Code** — `C:\Users\Administrator\AppData\Local\Programs\Microsoft VS Code\Code.exe`
- **Git** — `C:\Program Files\Git\bin\git.exe`
- **Node.js** — `C:\Program Files\nodejs\node.exe`
- **Python** — via venv del proyecto

### Diseno
- **CorelDRAW** — verificar instalacion
- **GIMP** — verificar instalacion

### Comunicacion
- **Discord** — verificar instalacion
- **WhatsApp** — verificar instalacion

### Utilidades
- **opencode** — `opencode-ai` npm global (shim)
- **omniroute** — npm global
- **9router** — npm global
- **ollama** — instalador local

## Como registrar un programa nuevo
Agregar una entrada con: nombre, ruta exacta, notas (si tiene CLI, puertos, etc.)
