### Correcciones Críticas Aplicadas

1. **`live` scope bug** → `window.liveData` global para loop de dibujo
2. **Draw loop no arrancaba** → `startLoop()` llamado en `initHUD` tras resize
3. **Anillos no se dibujaban** → `ctx.arc` con `strokeStyle` correcto por anillo
4. **Nodos no aparecían** → `initNodes()` posiciona 12 nodos en 3 radios concéntricos
5. **Líneas núcleo→nodo** → `ctx.moveTo(cx,cy); ctx.lineTo(n.x,n.y)` con alpha animado `sin(now/2000)`
6. **Partículas starfield** → 90 partículas con deriva suave + wrap-around
