Atlas — SPEC C2 · Bucle de Cierre Forzoso

Contrato de implementación · v1.0 · 14/08/2026 · Regla de lectura: cada REQ bloqueante; evidencia obligatoria.
Lema: el agente NO cierra tareas. Cierra el código.

01 · Propósito

Convertir el cierre de tareas de promesa (skills, prompts) a ley (código determinista). Un controlador externo corre el bucle agente→verificador y no sale hasta 100% de criterios + calidad, o escala al humano con reporte exacto. Es el "Hard Stop" de GOVERNANCE.md ejecutado como sistema, no como texto.

02 · Diagnóstico (por qué queda a medias hoy)

  • Skills son texto: el LLM las ignora bajo contexto largo o cortes. Nada lo obliga.
  • Sin re-inyección: opencode ejecuta un turno y termina; lo pendiente muere ahí.
  • Auto-evaluación sesgada: preguntar al agente "¿terminaste?" = el alumno se califica solo.
  • Progreso invisible: sin criterios ni %, "a medias" no se ve.
  • Evidencia del reporte 13/08: chat hardcodeado, sin switch runtime, tareas que mueren silenciosas (stderr DEVNULL).

03 · Arquitectura

TÚ → orden
      ↓
CONTRATO (criterios verificables; sección=criterio; %=cumplidos/total)
      ↓
┌────────────── BUCLE · atlas_controller.py (código, no LLM) ──────────────┐
│ 1. turno_agente(): opencode run con SOLO pendientes inyectados            │
│ 2. verificar(): EJECUTA evidencia real por criterio (nunca pregunta)      │
│ 3. progreso % + pendientes → dashboard /api/tareas + chat                 │
│ 4. <100% → re-inyecta (intento n/max)                                     │
│ 5. =100% → critic(): modelo APARTE, JSON forzado (calidad)                │
│    calidad NO → re-inyecta huecos                                         │
│ 6. max intentos / timeout / costo → ESCALADA con reporte (nunca silencio) │
└───────────────────────────────────────────────────────────────────────────┘
      ↓
CIERRE: contrato+evidencias → vault/<proj>/tasks/ + dashboard + runbook si aplica

05 · Controlador (esqueleto drop-in)

# atlas_controller.py
import json, subprocess, time, urllib.request, urllib.error
from pathlib import Path
from datetime import datetime, timedelta
STATE = Path("memory_data/state/tasks"); STATE.mkdir(parents=True, exist_ok=True)

def guardar(c):
    (STATE/f"{c['task_id']}.json").write_text(json.dumps(c, ensure_ascii=False, indent=2), encoding="utf-8")

def notificar(c):
    msg = f"{c['task_id']}: {c['progreso_pct']}% · intento {c['intentos']}/{c['max_intentos']}"
    pendientes = [x["id"] for x in c["criterios"] if x["estado"]=="FAIL"]
    if pendientes: msg += f" · falta {pendientes}"
    print(f"[controller] {msg}")

def cerrar(c):
    c["estado"]="TERMINADA"; c["evidencias"].append({"cierre": datetime.now().isoformat()})
    guardar(c); notificar(c)
    # copiar contrato a bóveda
    vault = Path("memory_data/vault/agente_ia/tasks"); vault.mkdir(parents=True, exist_ok=True)
    (vault/f"{c['task_id']}.json").write_text(json.dumps(c, ensure_ascii=False, indent=2), encoding="utf-8")
    return c

def escalar(c):
    c["estado"]="ESCALADA"; guardar(c)
    notificar(c)
    return c

def registrar_claim(c):
    """Registra si el agente declaró 'listo' pero el verificador no está en 100%"""
    if c.get("_agent_claimed_done") and c["progreso_pct"] < 100:
        c.setdefault("trust_log", []).append({"ts": datetime.now().isoformat(), "pct": c["progreso_pct"], "claim": True})

EXEC = {
    "comando":  lambda v: _exec_cmd(v),
    "archivo":  lambda v: _exec_file(v),
    "endpoint": lambda v: _exec_endpoint(v),
    "test":     lambda v: _exec_test(v),
}

def _exec_cmd(v):
    try:
        r = subprocess.run(v["cmd"], shell=True, capture_output=True, text=True, timeout=30)
        ok = (r.returncode == 0) and (v.get("esperado","") in (r.stdout + r.stderr))
        return ok, r.stdout[:500]
    except Exception as e:
        return False, str(e)

def _exec_file(v):
    p = Path(v["ruta"])
    if not p.exists(): return False, "no existe"
    if "contiene" in v:
        return v["contiene"] in p.read_text(encoding="utf-8"), "contiene check"
    return True, "existe"

def _exec_endpoint(v):
    try:
        req = urllib.request.Request(v["url"], method="GET")
        with urllib.request.urlopen(req, timeout=10) as r:
            body = r.read().decode("utf-8", errors="replace")
            ok = (r.status == 200) and (v.get("esperado","") in body)
            return ok, f"status={r.status}"
    except Exception as e:
        return False, str(e)

def _exec_test(v):
    try:
        r = subprocess.run([".venv\\Scripts\\python.exe", "-m", "pytest", "-q", v.get("path","tests/unit/")], capture_output=True, text=True, timeout=120, cwd=str(Path(__file__).parent))
        ok = "failed" not in r.stdout.lower() and r.returncode == 0
        return ok, r.stdout[-500:]
    except Exception as e:
        return False, str(e)

def correr(task_id):
    c = json.loads((STATE/f"{task_id}.json").read_text(encoding="utf-8"))
    while c["estado"]=="EN_CURSO":
        timeout_dt = datetime.fromisoformat(c["timeout"])
        if c["intentos"]>=c["max_intentos"] or datetime.now() > timeout_dt:
            return escalar(c)
        pendientes=[x for x in c["criterios"] if x["estado"] not in ("OK",) and x["tipo"]!="humano"]
        if not pendientes:
            ok_n=sum(1 for x in c["criterios"] if x["estado"]=="OK" or x["tipo"]=="humano")
            c["progreso_pct"]=round(100*ok_n/len(c["criterios"]))
            if c["progreso_pct"]==100:
                q = critic(c)
                if q["pass"]: return cerrar(c)
                c["evidencias"].append({"huecos_calidad": q["huecos"]})
            guardar(c); notificar(c); break
        turno_agente(c, pendientes)
        c["intentos"]+=1
        verificar(c)
        registrar_claim(c)
        if c["progreso_pct"]==100:
            q = critic(c)
            if q["pass"]: return cerrar(c)
            c["evidencias"].append({"huecos_calidad": q["huecos"]})
        guardar(c); notificar(c)
        time.sleep(2)

def turno_agente(c, pendientes):
    prompt=(f"CONTRATO {c['task_id']}. Orden: {c['orden_literal']}. "
            f"Pendientes: {[(p['id'],p['descripcion']) for p in pendientes]}. "
            f"Evidencia previa: {c['evidencias'][-3:]}. Intento {c['intentos']+1}/{c['max_intentos']}. "
            "Resuelve SOLO los pendientes. No declares éxito: el verificador lo comprobará.")
    subprocess.run(["opencode","run",prompt], timeout=600)

def verificar(c):
    for cr in c["criterios"]:
        if cr["estado"]=="OK" or cr["tipo"]=="humano": continue
        ok, ev = EXEC[cr["tipo"]](cr["verificacion"])
        cr["estado"], cr["evidencia"] = ("OK" if ok else "FAIL"), ev
    ok_n=sum(1 for x in c["criterios"] if x["estado"]=="OK" or x["tipo"]=="humano")
    c["progreso_pct"]=round(100*ok_n/len(c["criterios"]))

07 · Crítico (calidad)

  • Modelo distinto al generador (orquestador elige otro provider si existe).
  • Salida JSON forzada con schema {"pass":bool,"huecos":[...]}; parse inválido → 1 retry → ESCALADA.
  • Checklist: orden cubierta punto por punto · estándar C1 si es entregable · sin placeholders · evidencia presente.

09 · Límites y escalada

  • max_intentos default 5 · timeout por nivel (L1 10min, L2 20, L3 40) · costo_max estimado vía routing_log.
  • Escalada = toast + chat + nota en bóveda con: % real, criterios FAIL, evidencias de intentos, siguiente acción sugerida. Nunca silencio.

10 · Métrica de confianza

Agente dice "listo" y verificador <100% → entrada en trust_log. Patrón ≥3 en 7 días → acción automática sugerida en dashboard: cambiar modelo para ese tipo de tarea / ajustar style_profile. Se registra, no se castiga a ciegas.

12 · E2E de referencia

Caso: configurar extensión en el navegador del usuario
  1. Contrato: CR-1 aparece en lista (ui) · CR-2 toggle activo (ui) · CR-3 config aplicada (captura+OCR) · CR-4 navegador funcional (open_app+captura).
  2. Intento 1: agente opera; verificador ve CR-1/CR-2 OK, CR-3 FAIL → 50% → re-inyecta "falta CR-3, evidencia: captura X".
  3. Intento 2: CR-3 OK → 100% → crítico juzga calidad del proceso → CIERRE → contrato en bóveda + runbook candidato.

  • 9 REQs con evidencia · panel /api/tareas vivo · 1 tarea real cerrada por el bucle · 1 escalada simulada con reporte.
